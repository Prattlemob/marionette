# M2.3 — Backpressure, Rate & Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the bridge reliable under slow/misbehaving agents: latest-wins observation coalescing with a hard bound, per-session cadence via a new `configure` message, ping/pong liveness, clean shutdown, and the tracked lifecycle/JSON-strictness carry-overs.

**Architecture:** Backpressure is a writability gate in `BridgeServer.sendObservation` (Netty `WriteBufferWaterMark` is the hard bound; a one-slot stash holds the latest unsent frame, flushed on `channelWritabilityChanged`). Protocol logic stays in `ProtocolSession`/`MessageParser` (network thread); all game-state changes stay on the tick thread in `MarionetteClient`. Spec lands in `protocol/v1.md` before any implementation (CLAUDE.md rule).

**Tech Stack:** Java 21, NeoForge 21.8.x (MC 1.21.8), Netty (`netty-codec-http` 4.1.118 jar-in-jar), Gson 2.11.0 (the `Strictness` API is available — verified on the runtime classpath), JUnit 5 headless tests, Python `websockets` for examples.

In `MessageParser`, replace the body of `parse` up to the `envelopeId` call and add the helper. New imports: `java.io.IOException`, `java.io.StringReader`, `com.google.gson.Strictness`, `com.google.gson.stream.JsonReader`, `com.google.gson.stream.JsonToken`.

```java
public static ParsedMessage parse(String text) {
    JsonObject json = strictJsonObject(text);
    JsonPrimitive id = envelopeId(json);
    try {
        return parseTyped(json, id);
    } catch (ProtocolError e) {
        // Attach the envelope id so error replies can echo it.
        throw e.id() != null ? e : new ProtocolError(e.code(), e.getMessage(), id);
    }
}

/**
 * RFC 8259 parsing. Gson's JsonParser.parseString is lenient (unquoted
 * keys, single quotes, NaN); the wire contract is strict JSON, and
 * protocol/README.md makes later tightening a breaking change — so be
 * strict from the start (docs/decisions.md, M2.3).
 */
private static JsonObject strictJsonObject(String text) {
    JsonReader reader = new JsonReader(new StringReader(text));
    reader.setStrictness(Strictness.STRICT);
    JsonElement element;
    try {
        element = JsonParser.parseReader(reader);
        if (reader.peek() != JsonToken.END_DOCUMENT) {
            throw new ProtocolError(ErrorCode.INVALID_JSON, "trailing content after JSON value");
        }
    } catch (JsonParseException | IOException e) {
        throw new ProtocolError(ErrorCode.INVALID_JSON, "malformed JSON");
    }
    if (!element.isJsonObject()) {
        throw new ProtocolError(ErrorCode.INVALID_JSON, "message must be a JSON object");
    }
    return element.getAsJsonObject();
}
```

Delete the old try/catch block that used `JsonParser.parseString`.

private static Integer optionalRangedInt(JsonObject json, String name, int min, int max) {

```java
/**
 * Send one observation frame; silently dropped when no controller is
 * ready. A slow-reading agent (channel unwritable) gets frames coalesced
 * to latest: the newest frame waits in a one-slot stash, flushed when the
 * channel drains; intermediate frames are dropped and counted. Setting
 * the stash to null before a direct write is what keeps latest-wins
 * ordering: a newer frame always supersedes a stashed older one.
 */
public void sendObservation(String json) {
    Channel channel = controller.get();
    if (!controllerReady.get() || channel == null || !channel.isActive()) {
        return;
    }
    if (channel.isWritable()) {
        pendingObservation.set(null);
        channel.writeAndFlush(new TextWebSocketFrame(json));
    } else {
        pendingObservation.set(json);
        coalesced.incrementAndGet();
    }
}

/** Observation frames deferred/dropped for a slow reader since this controller attached. */
public long coalescedObservations() {
    return coalesced.get();
}
```

@Override
public void channelWritabilityChanged(ChannelHandlerContext ctx) throws Exception {
    if (ctx.channel() == controller.get() && ctx.channel().isWritable()) {

        if (pending != null) {
            ctx.writeAndFlush(new TextWebSocketFrame(pending));
        }
    }
    super.channelWritabilityChanged(ctx);
}

"""Connects, completes hello, then never reads — the M2.3 slow-consumer probe.

import asyncio, json, sys
import websockets

PORT = int(sys.argv[1]) if len(sys.argv) > 1 else 24680

async def main():
    # max_queue=1 + never calling recv(): the library's flow control stops
    # reading the transport, so TCP backpressure reaches the mod.

        print("hello reply:", await ws.recv())
        print(f"stalling: not reading for {STALL_SECONDS}s", flush=True)
        await asyncio.sleep(STALL_SECONDS)

asyncio.run(main())
